📋 10/22 작업 종합 — API 보안 · ML 이상탐지

프로젝트 후보를 두 갈래로 정리했고, ML 탐지 코드는 가상 데이터로 동작 검증까지 했습니다 🙌


1️⃣ Shadow API 탐지
https://github.com/zeldaim/shadow_APT

• 통관·물류 플랫폼(EKS)에서 명세 × 트래픽 × 자산을 대조해 Shadow/Zombie API 자동 탐지
• Shadow = 존재를 모르는 API / Zombie = 죽었어야 하는데 살아 있는 API
• 미러링은 오가는 트래픽만 보임 → 자산 조회를 결합해 "조용히 열려만 있는 API"까지 잡는 게 차별점
• 통관·물류 선정 이유: 파트너 API가 많고, 다국적 트래픽, 관세청·AEO 거버넌스와 연결


2️⃣ ML 이상탐지 (Isolation Forest)
https://github.com/zeldaim/ml_detection

• 원리: 데이터를 아무렇게나 반으로 자를 때, 몇 번 만에 혼자 남나 → 빨리 혼자 남을수록 수상
• 공격 예시를 학습하지 않아도 됨 (처음 보는 공격도 탐지)
• ✅ 검증: 정상 IP 14개 + 빠른 브루트포스 + 40초 간격 느린 공격 → 공격 IP 2개만 정확히 탐지
• "룰은 침묵, ML은 탐지" 장면 확보 (가상 데이터라 실제 Wazuh 랩에서 재확인 필요)


3️⃣ ML vs LLM 비교 실험 (계획)

• ML = 우리 데이터의 "평소"와 비교 / LLM = 세상 지식으로 해석·설명
• 비교: Wazuh 룰 · ML · LLM · ML+LLM 조합
• 채점: 탐지율 · 오탐률 · 탐지 시간 · 비용 · 설명력
• 모니터링 지표(Prometheus) 추가 권장 → 로그에 안 찍히는 공격(유출, 크립토마이닝)까지
• 클라우드 구축은 로컬 완성 후 2단계 검증용 (AWS 워크샵 3일 활용)
