📋 *10/22 작업 종합 — API 보안 · ML 이상탐지*

프로젝트 후보를 두 갈래로 정리했고, ML 탐지 코드는 가상 데이터로 동작 검증까지 했습니다 🙌

*1️⃣ Shadow API 탐지* → https://github.com/zeldaim/shadow_APT
• 통관·물류 플랫폼(EKS)에서 *명세 × 트래픽 × 자산* 3원 대조로 Shadow/Zombie API 자동 탐지
• 미러링은 오가는 트래픽만 보임 → 자산 조회·스캔을 결합해 "조용히 열려만 있는 API"까지 잡는 게 차별점
• Shadow = 존재를 *모르는* API / Zombie = 죽었어야 하는데 *살아 있는* API
• 통관·물류 선정 이유: 파트너 API 多, 다국적 트래픽, EDI→API 전환기, 관세청·AEO 거버넌스

*2️⃣ ML 이상탐지 (Isolation Forest)* → https://github.com/zeldaim/ml_detection
• 원리: 아무 데나 선을 그어 나눌 때 *몇 번 만에 혼자 남나* — 빨리 고립될수록 수상
• 공격을 학습하지 않음(라벨 불필요), 거리를 재지도 않음
• ✅ 검증: 정상 IP 14개 + 빠른 브루트포스 + 40초 간격 느린 공격 → *공격 IP 2개만 정확히 탐지*
• "룰은 침묵, ML은 탐지" 장면 확보 (단, 가상 데이터 → 실제 Wazuh 랩에서 재확인 필요)

*3️⃣ ML vs LLM 비교 실험 (계획)*
• ML = 우리 데이터의 "평소"와 비교 / LLM = 세상 지식으로 해석·설명
• 비교: Wazuh 룰 · ML · LLM · ML+LLM 조합 → 탐지율·오탐률·탐지시간·비용·설명력 채점
• 모니터링 지표(Prometheus) 추가 *권장* — 유출·크립토마이닝처럼 로그에 안 찍히는 공격 탐지
• 클라우드 구축은 *로컬 완성 후 2단계 검증용* (AWS 워크샵 3일 활용)
